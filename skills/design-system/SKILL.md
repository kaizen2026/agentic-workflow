# Design System Skill

When invoked:
1. Review component UI layouts and styling against modern design standards.
2. Enforce clean, muted color palettes (subtle slates, neutral greys, soft accent tones). Avoid aggressive high-saturation primary colors.
3. Verify visual hierarchy: consistent spacing scale, clear typography contrast, and accessible interactive states.
4. Ensure components remain responsive, scannable, and clutter-free across all viewport break-points.
