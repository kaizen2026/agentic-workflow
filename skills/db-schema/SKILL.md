# DB-Schema Skill

When invoked:
1. Analyze requested data models or migration targets.
2. Output normalized relational schema definitions (SQL, ORM schemas, or Dataverse/MS-SQL scripts).
3. Index key query paths (foreign keys, filtering criteria, dynamic sorting).
4. Generate reversible UP/DOWN migration scripts with non-destructive fallback strategies.
