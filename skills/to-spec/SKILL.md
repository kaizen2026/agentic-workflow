# To-Spec Skill

When invoked:
1. Synthesize all recent context, requirements, and architectural decisions.
2. Generate a structured spec file inside .agents/issues/spec.md.
3. Include: Problem Statement, Target Architecture, User Stories, Acceptance Criteria, and Testing Requirements.
4. Keep the output clean and deterministic for multi-session execution.
